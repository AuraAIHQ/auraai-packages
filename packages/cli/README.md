# @auraaihq/cli

> CLI tool for Agent24-Desktop module development. Provides scaffolding, debugging, and module lifecycle management.

**Status**: M0 placeholder. Implementation begins M1.

## Planned commands

```bash
auraai init <module-name>      # 脚手架新模块（基于 @auraaihq/sdk 模板）
auraai dev                     # 本地开发，HMR
auraai test                    # 运行模块测试
auraai publish                 # 发布到 npm
auraai install <module>        # desktop 中装载模块
auraai remove <module>         # desktop 中卸载模块
```
